It clears caches, removes apps with their leftovers, runs maintenance tasks, maps disk usage, and shows live system status. Built with Shell and Go, licensed GPL-3.0. Mole for Mac (https://mole.fit) is the separate paid native app that covers the same jobs with a GUI.</p><p class="project-live-fact">65,294<!-- --> GitHub stars · <!-- -->2,288<!-- --> forks<!-- --> · latest release V1.53.0</p></section><section class="project-section" aria-labelledby="choose-title"><h2 id="choose-title">Choose <!-- -->Mole<!-- --> when</h2><ul class="plain-list"><li>macOS running slow</li><li>disk space full on Mac</li><li>clean junk files on macOS</li><li>free CleanMyMac alternative</li><li>clean Xcode derived data and caches</li><li>remove old Docker images and npm cache</li><li>Homebrew cache taking too much space</li><li>clean a Mac from the terminal</li></ul></section><section class="project-section" aria-labelledby="features-title"><h2 id="features-title">Key features</h2><ul class="plain-list"><li>`mo clean` deep cache cleanup plus leftovers from already-uninstalled apps</li><li>`mo uninstall` removes installed apps together with their leftover files</li><li>`mo optimize` refreshes system caches and services</li><li>`mo analyze` visual disk explorer for finding what takes the space</li><li>`mo status` live system health dashboard in the terminal</li><li>`mo purge` and `mo installer` clear project build artifacts and stale installers</li><li>`mo touchid` enables Touch ID for sudo</li><li>Every destructive command supports `--dry-run` to preview before acting</li></ul></section><section class="project-section" aria-labelledby="compare-title"><h2 id="compare-title">Compared with</h2><p>CleanMyMac, OnyX, AppCleaner, DaisyDisk<!-- -->.</p></section><section class="project-section" aria-labelledby="details-title"><h2 id="details-title">Practical details</h2><dl class="details-list"><dt>Requirements</dt><dd>macOS (macOS 14 or later for the Homebrew path). Mole for Mac, the native GUI app at https://mole.fit, is a separate paid product with a $19 one-time license.</p></article><article><h3>Is Mole safe to use?</h3><p>Yes. Mole uses safe helper functions and never runs raw rm -rf. It applies path validation, protected-directory rules, and conservative cleanup boundaries, and every destructive operation supports dry-run mode.</p></article><article><h3>What does Mole clean?</h3><p>Browser caches (Chrome, Arc, Brave, Safari), Xcode derived data, Homebrew cache, npm/pnpm/yarn cache, Docker unused images, system logs, old AI coding assistant versions (Copilot CLI, Claude Code, Cursor Agent), and app-specific temp files.</p></article><article><h3>How do I install and update Mole?</h3><p>Install with Homebrew: `brew install mole`. Or with the script: `curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash`. Update to stable: `mo update`. Update to the latest unreleased main build: `mo update --nightly` (script install only).</p></article><article><h3>What are the main Mole commands?</h3><p>`mo clean` (cache and leftover cleanup), `mo uninstall` (app removal with leftovers), `mo optimize` (system maintenance), `mo analyze` (disk explorer), `mo status` (live system dashboard), `mo purge` (project build artifacts), `mo installer` (stale installer sweep). Each supports `--dry-run` to preview before acting.</p></article><article><h3>Does Mole have a GUI?</h3><p>Yes. Mole for Mac at https://mole.fit is the native SwiftUI app. It is a separate paid product ($19 one-time, lifetime updates, 2 Macs per license) and adds a disk treemap, a bento status dashboard, a menu bar HUD, fan controls, startup management, and in-app app updates. The CLI stays free and open source for terminal workflows.</p></article><article><h3>Does Mole work on Linux?</h3><p>No. Mole is built for macOS and relies on macOS-specific APIs like mdfind, LaunchAgent/LaunchDaemon, and TCC for safe operations.
